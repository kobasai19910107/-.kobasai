# 新作オートバトルゲーム：試作品仕様 v0.1

既存の shattered_crown_echo とは別の新作。

## ゲームの基本
- 主人公1人が多数の敵と戦う完全オートバトル。
- 移動・攻撃・回避・技・必殺技はすべて自動。
- プレイヤーは戦闘後に3択から強化を選ぶ。
- 格闘・武器・射撃・特殊能力を混ぜつつ特化する。
- 技枠は主力1、補助3、大技1。
- 完成版は短い挑戦を繰り返し、永久解放も進める形式。

## ビジュアル
- 主人公は白い体、丸い頭、顔のパーツなしの可愛い三頭身。
- 髪や服はなく、丸みのある手足。ポーズで感情を表現する。
- 敵は可愛いスライム、ゴブリン、森の猪、石のゴーレム。
- 横視点、奥行きのある背景、コミック風の派手な演出。
- ヒットストップ、吹き飛ばし、短いズームやスローを使う。
- 流血・欠損は使わない。

## 最初の試作品
全3戦。戦闘後に回復と3択強化を挟む。
第1戦：スライムとゴブリン。
第2戦：スライム、ゴブリン、森の猪。
第3戦：ゴーレムと取り巻き。
全敵撃破で勝利。主人公HP0で敗北。

## 技
- 主力：パンチ→パンチ→キックの連続格闘。
- 補助：敵を打ち上げるアッパー。
- 補助：打ち上げた敵に追撃する空中銃撃。
- 補助：囲まれたときに使う回し蹴り。
- 大技：ゲージがたまると自動発動する巨大ハンマー。
初期は主力のみ。残りは戦闘後に獲得する。
基本連携は必要な技がそろえば成立する。
ゴーレムには打ち上げ耐性を持たせる。

## 強化選択
新技の習得、所持技の進化、連携強化から3択。
少なくとも1候補は現在の構成ですぐ役立つものにする。
空中銃撃はアッパー所持時のみ候補に出す。
第1戦後：アッパー／回し蹴り／巨大ハンマーから選択。
第2戦後：未取得技と所持技の進化から選択。

## 自動判断
危険への回避、満ゲージの大技、空中追撃、
包囲時の範囲技、アッパー、主力攻撃の順で判断。
各技に待ち時間を設定する。
死亡した敵を狙い続けない。
敵がいないときに大技を消費しない。

## HP・保存
最大HP100。HPは次戦へ引き継ぐ。
勝利後に最大HPの20%回復する。数値は仮設定。
回復と報酬は各戦闘につき一度のみ。
強化画面で保存。戦闘途中で閉じた場合は
その戦闘の開始時状態から再開する。
再挑戦で今回のHP・技・ゲージを初期化する。

## UI
上部：HP、戦闘数、敵残数、一時停止。
下部：技5枠、待ち時間、大技ゲージ、速度変更。
技アイコンは状態表示。手動発動ボタンにはしない。
携帯横画面で文字やボタンが欠けないこと。

## 実装方針
携帯ブラウザで遊べる構成を優先。
エンジンは未決定。Godot必須ではない。
永久育成・ショップ・オンライン機能は試作品の範囲外。
数値は調整可能なデータとして分離する。
イラスト1枚を表示するだけではなく、
主人公・敵・攻撃・吹き飛ばしを個別に動かす。

## 完成条件
- 3戦クリア、敗北、再挑戦が動作する。
- 技の自動発動とアッパー→空中銃撃が動作する。
- 強化選択が次戦に反映される。
- 回復や報酬の二重取得が起きない。
- 保存・再開、一時停止、速度変更が動作する。
- 携帯で遊べる画面になっている。

## Codexへの依頼
この仕様に沿って独立した新作の試作品を実装する。
既存ゲームには変更を加えない。
主力戦闘→補助と連携→大技と敵→3戦と強化
→保存と画面調整の順に進める。
必要な細部は仮設定して進め、調整理由を記録する。
検証結果と実行方法を報告する。

## 実装した試作版「まるっとファイター」

既存ゲームとは独立した、外部素材・外部ライブラリ不要のCanvas製Webゲームです。
白い顔なしの三頭身主人公と4種類の敵を個別に描画・アニメーションします。

### 実行方法

Node.jsはテスト用です。ゲームの起動にはPython 3とブラウザだけで十分です。

```sh
cd /path/to/-.kobasai
python3 -m http.server 8000 --bind 0.0.0.0
```

PCのブラウザで `http://localhost:8000` を開きます。
初期は連続格闘のみです。第1戦後にアッパー・回転蹴り・巨大ハンマーの
いずれかを習得し、第2戦後に未習得技または進化を選びます。
アッパー所持時だけ空中銃撃が候補に出ます。
1回の挑戦では全技はそろいません。再挑戦して別の構成を試せます。

### iPhoneのSafariで試遊

- PCにこのリポジトリをコピーし、上記サーバーを起動します。
- PCとiPhoneを同じWi-Fiに接続します。
- Safariで `http://PCのLAN内IPアドレス:8000` を開きます。
- PC側のファイアウォールでは必要に応じてローカルネットワークからの8000番への接続を許可します。
- 横向きがおすすめです。Safariのツールバーが表示されてもページをスクロールできます。

クラウド環境のlocalhostはiPhoneから直接アクセスできません。
遠隔で試す場合は `index.html`、`style.css`、`app.js`、`game.js`、`motion.js` を
GitHub Pagesなどの静的Webホスティングに配置し、そのHTTPS URLをSafariで開いてください。
この実装作業ではホスティングへの公開は行っていません。

### 操作・保存

戦闘は完全自動で、操作は強化選択・一時停止・速度切り替え（1倍／2倍）だけです。
技枠は状態表示です。別タブへ移動すると自動的に一時停止します。
強化画面と各戦闘の開始時状態をlocalStorageへ保存します。
戦闘中のリロードはその戦闘の開始時から「つづきから」で再開できます。
回復と強化の二重取得を防ぎ、クリア／敗北後には保存を消去します。
保存が利用できないブラウザでは画面上に通知し、その場でのプレイを継続します。

### 仮の調整値と構成

`game.js` の `CONFIG` にHP、回復量、敵、技、戦闘編成を集約しています。
HP100、戦闘後回復20、パンチ13ダメージ、ハンマー60ダメージを初期値としました。
短い試遊で3戦を体験できるように、回避を強めに設定しています。
ゴーレムはHP210・打ち上げ無効。技進化は初期ダメージの40%分を加算します。
主人公・敵・攻撃エフェクトは仮の図形素材です。音声・永久育成・オンライン機能は未実装です。

- `game.js`: 自動戦闘・報酬・状態遷移と調整データ
- `app.js`: Canvas描画、画面、保存、演出（吹き飛ばし・ヒットストップ・画面揺れ）
- `style.css`: スマートフォンの縦横表示、セーフエリア、44px以上のボタン

### 検証

```sh
npm test
```

既存依存関係のインストールは不要です。Node.jsの組み込みテストで
3戦、回復／報酬の一度きりの処理、保存状態の復元、空中連携、
ゴーレム耐性、範囲技、大技、敗北、再挑戦と自然な戦闘進行を検証します。
実機iPhoneでのSafari・タッチ・ブラウザUIを含む最終確認は、上記URLで行ってください。

### モーションの改善

歩幅に連動する手足と重心移動、関節の曲がり、連撃のキック、技別の戻り動作、
攻撃直前の構え、滑らかな回避表示を追加しました。敵には進行方向への向き直り、
スライムの弾み、被弾時の傾き、着地のつぶれを付けています。
モーションは `motion.js` に分離し、戦闘時間に連動するため一時停止と速度変更に追従します。
戦闘のダメージ・報酬・保存形式は維持しています。

### アニメ調の戦闘モーション（第2改修）

技は「ため→命中→振り抜き→構え」の時間付きキーフレームで描画し、
実際の命中・ダメージ・ヒットストップを接触フレームに合わせました。
連撃はジャブ→クロス→キック、ハンマーは頭上からの振り下ろしです。
技の途中に別の技で上書きされず、射程外へ逃げた敵には空振りします。
回避は瞬間移動ではなく減速するステップ、歩行は接地と足の振り戻しを区別します。
敵には命中時のひるみ、重さに応じた吹き飛ばし、短い倒れ込みを加えました。
横画面は描画領域に合わせて背景の見える範囲を変え、キャラクターを小さく縮めず表示します。
戦闘のタイミングは変わりますが、HP・技のダメージ・報酬・保存形式は維持しています。
